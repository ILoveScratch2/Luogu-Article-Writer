# Luogu Article Writer Skill

洛谷专栏文章写作 Skill，为 Agent 提供针对洛谷专栏的写作规范与风格指导。

## 功能

基于对 50+ 篇洛谷专栏文章的语料分析蒸馏，涵盖：

- **4 种文章类型模板**：算法学习笔记、工具/插件介绍、技术探索、综合技术分享
- **洛谷 Markdown 规范**：`:::info/success/warning/error` callout 块、`line-numbers` 代码块、LaTeX 数学公式、图床链接格式
- **表达 DNA**：直入式开头、问答节奏、短句重击、括号幽默、删除线自嘲
- **写作决策指导**：代码放哪里、证明写不写、图片用不用、`---` 分隔符用法

## 触发词

在对话中包含以下任意词语时，Skill 自动激活：

> 帮我写洛谷文章 / 洛谷专栏 / OI 学习笔记 / 写篇算法文章 / 介绍一下这个工具 / 帮我写题解

## 核心写作原则

1. **直接进入问题**，不写"本文将介绍……"式开头
2. **问题优先，解法跟随**——读者先理解"为什么"，再看"是什么"
3. **真实思考轨迹**优于完美叙述，保留探索过程中的歪路与修正
4. **密度优先**，不加水，不写空洞过渡段和总结段
5. **诚实边界**：不知道就说不知道，推测就标注推测

## 使用方式

使用该命令安装 Skill（本地 Git 登陆 GitHub 账户需有该仓库访问权限）：

```
npx skills add ILoveScratch2/Luogu-Article-Writer
```

直接向 Agent 提出写作请求，例如：

```
帮我写一篇 Kruskal 重构树的学习笔记，我已经理解了算法，有例题 P4197。
```

```
帮我介绍一下我写的工具 CodeCodeCode。
```

Skill 会先识别文章类型，核查关键信息，再按对应模板和风格输出文章。

## 注意事项

> 该 Skill 只负责按照洛谷专栏的风格和规范输出文本，**不负责内容的正确性**。涉及算法细节、代码实现、平台语法等需要用户自行核实确认。
> Skill 输出的文章需要用户自行审核、测试、调整后再发布到洛谷专栏，以确保内容的准确性和格式的正确性。
> 不鼓励直接复制粘贴 Skill 输出的文章以达到批量生成专栏内容目的。

- 算法证明必须你自己想清楚了再让 Skill 排版，Skill 不为逻辑正确性负责
- 代码需要本地测试通过后再放入文章，Skill 不为代码正确性负责
- 洛谷 Markdown 语法和 CDN 地址可能随平台更新变化，以实际测试为准
- 图片需要自己截图或绘制后上传洛谷图床
