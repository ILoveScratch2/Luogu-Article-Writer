# 文章类型与内容模式调研

来源：本地语料（d:\Articles），100% 一手来源。

## 文章类型分类

### 1. 算法学习笔记（OI 算法）
代表：Kruskal 重构树、Miller-Rabin & Pollard-rho、斜率优化初步、二进制拆分

**典型结构：**
1. （可选）前言：学习动机 / 触发事件
2. 算法核心概念定义
3. 举例说明（通常有图）
4. 性质列举（编号列表）
5. 证明（`> $Proof：$` 格式，引用块）
6. 例题一道（模板题，含题意分析+代码）

**代码风格：**
- 竞赛风格：`#include <bits/stdc++.h>`、`using namespace std;`
- 短变量名、全局数组
- 代码放 `:::info[code]` 中，AC 代码放 `:::success[参考代码]`

**数学密度：** 高，大量公式、复杂度标注

### 2. 工具/插件介绍
代表：Article2PDF、TouchFish、CompilerIDE、WSL

**典型结构：**
1. 痛点描述（"你是否有过以下烦恼？"）
2. 解决方案介绍（写什么/用什么）
3. 安装教程（Step-by-step，截图）
4. 功能列表或使用示例
5. （可选）源码

**特点：**
- 配有大量截图（洛谷 CDN 图片）
- 安装步骤用有序列表
- `:::warning` 和 `:::info` 频繁出现
- 代码块带行号

### 3. 技术探索/调查
代表：GCC sort 干掉、GCC 9.3 展开、位运算编译器 Bug

**典型结构：**
1. 发现/触发（某人提到了/某事引起了好奇）
2. 复现/实验（"丢进 godbolt 里面编译，启动！"）
3. 分析过程（逐步推理）
4. 结论（可能是意外或反直觉的）

**叙事特色：**
- 第一人称强烈，情感真实（"那我可就来兴趣了啊"）
- 戏剧性节奏：*若干秒之后*、"不行赶紧关掉 O2"
- 用 `---` 大量分隔单步推理

### 4. 综合技术分享
代表：现代 C++ 特性、初探现代 C++、工程代码码风

**典型结构：**
- `## Cx.xx 版本` 或 `## 特性名` 为二级标题
- 每个特性独立一节，互不依赖
- 有代码样例（带行号）
- 偶发个人评价："这个的好处就是…"

### 5. 个人叙述/成长类
代表：OI 之我的游戏发展史

**特点：**
- 时间顺序叙事
- 代码和文字交替，技术细节用于支撑叙事
- 语气最轻松，口语化

## 选题偏好
- 偏好"冷门但实用"：不常见算法技巧、底层工具分析
- 偏好"反直觉"：干掉 GCC sort、编译器 Bug
- 偏好"从问题出发"，不写 "我今天要介绍一个XX" 的泛泛开头
- 有明确读者群：OI 竞赛选手 + 对编程感兴趣的技术人

## 关于完整性
- 工具类：通常包含完整安装教程，力求读完就能上手
- 算法类：不追求覆盖所有变体，聚焦核心思想+一个例题
- 探索类：过程比结论更重要，记录"思考轨迹"
