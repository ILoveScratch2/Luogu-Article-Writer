# 表达 DNA 调研

来源：本地语料，分析 10+ 篇文章，100% 一手来源。

## 句式特征

### 主动提问引导读者
- "质数判断。考虑费马小定理……"（先结论后展开）
- "等一下，我们还没有榨干 $x$ 的用途。"（故意打断节奏）
- "什么，你记不住 $\{2,325,...\}$？那也可以退而求其次……"（模拟读者疑问）
- "为什么大家都认为快速排序的常数远小于堆排序……？"

### 短句重击
- "这是错的……"（接费马小定理段落，直接否定前设）
- "看来不太行。"（转折前的简短评价）
- "不行赶紧关掉 O2，它在干啥啊？？？"（感叹号连用）
- "好吧，训了几轮，发现结果不是很理想。"（低调开场）

### 括号内的补充/幽默
- "（你甚至可以将其和 Git 同时工作，一会用 Jujutsu，一会用 Git 都是完全可以的！）"
- "（当然用龟速乘也可以）"
- "（也融合了一些其他的社区的码风和我自己的一些习惯）"
- 括号内语气更轻松，常包含可选信息或自嘲

### 程度副词使用
- "毫不犹豫地回答"、"完全兼容"、"堪称完美"——对好工具表达强烈认可
- "最令人惊奇的是"、"最让我焦虑的"——情感浓度词

## 高频词汇

| 类型 | 词汇 |
|------|------|
| 逻辑过渡 | "不难发现"、"注意到"、"显然"、"我们可以" |
| 推理 | "考虑"、"我们先"、"那么"、"因此" |
| 不确定 | "感觉"、"猜测"、"可能"、"我猜测这可能与……相关" |
| 直接否定 | "这是错的"、"不太行"、"看来不太行" |
| 共识确认 | "Kruskal 求最小生成树都会吧"、"大家一般都知道" |
| 自我声明 | "受作者水平所限"、"这里不展开了"、"不进行证明" |

## 幽默方式
- **荒诞对比**："众所周知，算法导论上花费了超过一页进行证明的定理都不是好证明的东西（并查集的时间复杂度都只用了四页）"
- **自嘲**："~~无可救药~~地被吸引了过来"（删除线幽默）
- **夸张**："妈妈再也不用担心我把仓库玩坏了！"
- **模拟场景**："*若干秒之后*"（用斜体星号包围模拟旁白）
- **题外话**："什么，你记不住……？那也可以退而求其次"

## 确定性表达风格
- 对有把握的结论：直接陈述，不加"我认为"
- 对推测：明确标注（"我猜测"、"可能"）
- 对不会/不懂的：直接说"这里不展开了"、"不进行证明"
- 不用过度学术的 hedge 语言（"根据以上分析"、"由此可得"少见）

## 引用习惯
- 行内链接：`[标题](URL)` 格式，URL 指向洛谷题目、OIwiki、论文
- 标注来源："来自 OIwiki"、"来源：xxx 的文章"
- 提到他人时用洛谷 ID 或真名
- 偶有 "本文同步发表于…" 的跨平台声明

## 读者假设
- 默认读者是 OIer 或程序员，无需解释竞赛基础概念
- "Kruskal 求最小生成树都会吧" 直接跳过基础
- 但对专业/非 OI 知识（如 CPU 缓存、JVM）会解释
